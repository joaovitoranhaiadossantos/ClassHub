# ClassHub

Seja bem-vindo ao **ClassHub**!

O ClassHub é um projeto escolar que tem como objetivo **ajudar os alunos a tirarem suas dúvidas de forma online**. Este site pode ser usado para estudar para o ENEM, vestibular, provas ou apenas para reforçar o que já foi passado em sala. Apenas alunos com um cgm (cadastro geral de matrículas) pode entrar na plataforma para tirar dúvidas. Essa segurança na hora do cadastro garante que o número de perguntas sem sentido ou piadas sejam reduzidos ou inexistentes.

---

## Como o Sistema Foi Pensado?

Criamos um sistema em python com um sistema de banco de dados em sql. No Class Hub, apenas estudantes com CGM e apenas professores ou funcionários autorizados possam usar como administrador.

## O Que Tem no Nosso Repositório?

Pastas:

## Quer Usar o ClassHub?

Se você quiser testar o projeto no seu computador, siga os seguintes passos:

1.  **Baixe o código:** Faça o download ou clone este repositório.
2.  **Prepare o Banco de Dados:** Use o arquivo `portal_estudos.sql` no seu programa de banco de dados para criar a estrutura do portal.
3.  **Instale os pacotes:** Use o arquivo `requirements.txt` para instalar as bibliotecas necessárias do Python.
4.  **Rode o app:** Execute o arquivo `app.py` no terminal e abra o link que vai aparecer na tela (como `http://localhost:5000`) no seu navegador!
